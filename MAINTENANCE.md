# Maintenance runbook

The site in `datatalkwithankit/` is generated by `tools/build.py` (except `style.css`, `site.js` and the images, which are edited directly). Vercel deploys every push to `main`.

**Never edit the generated `.html`, `sitemap.xml`, `rss.xml`, `llms.txt` or `vercel.json` by hand. Edit `tools/build.py`, then rebuild.**

```bash
python3 tools/build.py   # regenerate pages
python3 tools/check.py   # must print "All checks passed."
```

## Twice-weekly health check
1. The latest production deployment in Vercel is `READY`.
2. These return 200: `https://www.datatalkwithankit.com/`, `/gpu-guide`, `/posts/h200-vs-mi300x`, `/sitemap.xml`, `/llms.txt`.
3. `https://datatalkwithankit.com` redirects to `https://www.datatalkwithankit.com`.
4. Vercel's domain config shows `misconfigured: false` and no `conflicts` for both the apex and `www` (a stray Dynadot parking A record has broken this before).
5. `python3 tools/check.py` passes.

## Weekly price refresh (Mondays)
Source: the lowest listed on-demand price per GPU-hour on getdeploying.com:
`/gpus/nvidia-h100`, `/gpus/nvidia-h200`, `/gpus/nvidia-b200`, `/gpus/nvidia-b300`, `/gpus/amd-mi300x`, `/gpus/amd-mi325x`, `/gpus/amd-mi355x`.

If any price moved by 5% or more:
1. Update the price in `GPUS` in `tools/build.py`.
2. Set `PRICE_DATE` and `PRICE_DATE_ISO` to today.
3. Add a newest-first entry to `GUIDE_CHANGELOG`, e.g. `("Nov 2, 2026", "Prices refreshed: B200 $3.75 → $3.49.")`.
4. Build, check, then commit and push. Confirm the deploy is `READY` and the live `/gpu-guide` shows the new date.

Don't change specs, add GPUs, or edit copy without the owner's approval.
