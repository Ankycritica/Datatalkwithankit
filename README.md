Personal site of **Ankit Dongare**, an AI engineer who measures what language models cost to run. Published studies include explicit assumptions and reproducible inputs. The capacity study includes a standalone Python script and the complete calculated results.

## Highlights

- **Will-it-fit calculator**: pick a model size and precision to see the three lowest estimated hourly costs across seven GPUs; expand for the full comparison.
- **A living GPU guide** at [/gpu-guide](https://www.datatalkwithankit.com/gpu-guide), updated quarterly.
- **Long-form posts** such as [H200 vs MI300X: what you're actually paying for](https://www.datatalkwithankit.com/posts/h200-vs-mi300x).
- Fast and dependency-free: plain HTML, CSS and JavaScript, light and dark themes, responsive down to phone width.
- SEO ready: canonical URLs, Open Graph images, JSON-LD, sitemap and RSS feed.

- **Reproducible capacity study**: 105 calculated scenarios at [/posts/llm-memory-capacity](https://www.datatalkwithankit.com/posts/llm-memory-capacity), with Python, JSON inputs, and CSV results. These are planning estimates, not hardware benchmark measurements.
- **Project case study**: [/projects/video-pipeline](https://www.datatalkwithankit.com/projects/video-pipeline).

- **AI models by GPU**: choose any of the seven GPUs and a weight precision to compare named Qwen, Llama, and DeepSeek examples. Each model links to its publisher card; memory budgets are estimates, with separate CUDA/ROCm guidance.

## Maintenance

Pages are generated by `tools/build.py`; see [MAINTENANCE.md](MAINTENANCE.md) for the build, checks, and the weekly price refresh.

## Publishing a post

1. Add the article source to `tools/content.py` or `tools/build.py`. Generated HTML should never be edited directly.
2. Add the article generation, listing, RSS item, and sitemap URL in `tools/build.py`.
3. Run `python3 tools/build.py` and `python3 tools/check.py`.
4. Push to `main`; Vercel deploys the generated site.

`tools/memory_study.py` is the maintained source for the downloadable study script. GPU capacities and dated prices come from `GPUS` in `tools/build.py`, so the guide, calculator, and study use the same snapshot.

## Run locally

```bash
cd datatalkwithankit && python3 -m http.server 8000
```
